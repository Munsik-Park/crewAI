## نظرة عامة

<Note>
يتطلب مزخرف `@human_feedback` إصدار **CrewAI 1.8.0 أو أحدث**. تأكد من تحديث تثبيتك قبل استخدام هذه الميزة.
</Note>

يمكّن مزخرف `@human_feedback` سير العمل البشري في الحلقة (HITL) مباشرة ضمن CrewAI Flows. يتيح لك إيقاف تنفيذ Flow مؤقتًا وعرض المخرجات لإنسان للمراجعة وجمع تعليقاته واختياريًا التوجيه إلى مستمعين مختلفين بناءً على نتيجة التعليقات.

هذا مفيد بشكل خاص لـ:

- **ضمان الجودة**: مراجعة المحتوى المُنشأ بالذكاء الاصطناعي قبل استخدامه
- **بوابات القرار**: السماح للبشر باتخاذ قرارات حرجة في سير العمل الآلي
- **سير عمل الموافقة**: تنفيذ أنماط الموافقة/الرفض/المراجعة
- **التحسين التفاعلي**: جمع التعليقات لتحسين المخرجات تكراريًا

## بداية سريعة

```python Code
from crewai.flow.flow import Flow, start, listen
from crewai.flow.human_feedback import human_feedback

class SimpleReviewFlow(Flow):
    @start()
    @human_feedback(message="Please review this content:")
    def generate_content(self):
        return "This is AI-generated content that needs review."

    @listen(generate_content)
    def process_feedback(self, result):
        print(f"Content: {result.output}")
        print(f"Human said: {result.feedback}")

flow = SimpleReviewFlow()
flow.kickoff()
```

## التوجيه مع emit

عند تحديد `emit`، يصبح المزخرف موجّهًا. يُفسَّر التعليق البشري الحر بواسطة LLM ويُختزل إلى إحدى النتائج المحددة:

```python Code
from crewai.flow.flow import Flow, start, listen, or_
from crewai.flow.human_feedback import human_feedback

class ReviewFlow(Flow):
    @start()
    def generate_content(self):
        return "Draft blog post content here..."

    @human_feedback(
        message="Do you approve this content for publication?",
        emit=["approved", "rejected", "needs_revision"],
        llm="gpt-4o-mini",
        default_outcome="needs_revision",
    )
    @listen(or_("generate_content", "needs_revision"))
    def review_content(self):
        return "Draft blog post content here..."

    @listen("approved")
    def publish(self, result):
        print(f"Publishing! User said: {result.feedback}")

    @listen("rejected")
    def discard(self, result):
        print(f"Discarding. Reason: {result.feedback}")
```

## التعلم من التغذية الراجعة

معامل `learn=True` يمكّن حلقة تغذية راجعة بين المراجعين البشريين ونظام الذاكرة. عند تمكينه، يحسّن النظام مخرجاته تدريجيًا بالتعلم من التصحيحات البشرية السابقة.

تُستخلص الدروس من كل رد، سواء وصل أثناء التشغيل أو استأنف لاحقًا Flow متوقفًا عبر `provider` غير متزامن. قبل المراجعة التالية تُطبَّق الدروس السابقة على المخرجات: يُعاد كتابة النص نصًا، ونموذج Pydantic بالنموذج نفسه ما لم يحتوِ على ما لا يراه LLM: قيمة سرية أو حقل مستبعد أو سمة خاصة تغيّرت عن قيمتها الافتراضية، وتُعرض المخرجات الأخرى مثل `dict` أو `list` دون تغيير.

<Note>
يوافق الإنسان على النسخة التي رُوجعت، وقد تختلف عمّا أعادته الدالة. في الخطوات التالية اقرأها من `self.last_human_feedback.output` (أو من وسيط المستمع)، فالحالة التي ضبطتها الدالة قبل المراجعة ما زالت تحتفظ بالنسخة الأصلية. وإذا توقف Flow بانتظار تغذية راجعة غير متزامنة، تُستعاد المخرجات من JSON عند الاستئناف، فيصل نموذج Pydantic على شكل `dict`.
</Note>

## التغذية الراجعة البشرية غير المتزامنة (غير محجوبة)

استخدم معامل `provider` لتحديد استراتيجية جمع تعليقات مخصصة تتكامل مع أنظمة خارجية مثل Slack والبريد الإلكتروني وWebhooks وواجهات API.

عند الاستئناف عبر `from_pending` ثم `resume` أو `resume_async` مع `emit`، لا تُنفَّذ الدالة التي خضعت للمراجعة مرة أخرى، ويستمر التشغيل من حيث توقفت المراجعة كما لو أُجيب عنها فورًا. تتلقى مستمعات الدالة المراجَعة وموجّهاتها وشروط `or_` المرتبطة بها سلسلة النتيجة، وتتلقى مستمعات النتيجة المختارة `HumanFeedbackResult`. وتُنفَّذ أيضًا الخطوات التي قطعها الإيقاف: المستمعات الأخرى للخطوة التي أدت إلى المراجعة، والموجّهات التي لم تُنفَّذ بعد، والبدايات (start) التي تنتظر نتيجة. تعمل عملية الدمج `and_` مرة واحدة عند اكتمال جميع خطواتها، وتتلقى قيمة الخطوة التي أكملتها؛ فالدمج بين الدالة المراجَعة والخطوة التي استدعتها يتلقى قيمة تلك الخطوة. وبدون `emit` أيضًا لا تُنفَّذ الدالة المراجَعة مرة أخرى عند الاستئناف: تتلقى مستمعاتها `HumanFeedbackResult`، وتُنفَّذ كذلك الخطوات التي قطعها الإيقاف. تُعيد `resume()` و`resume_async()` مخرجات آخر دالة نُفّذت، كما في التشغيل الذي يُجاب فيه عن المراجعة فورًا. تعتمد عمليات الدمج وشروط `or_` التي تعمل مرة واحدة والخطوات المقطوعة على سجل يحفظه وقت التشغيل مع السياق المعلّق. الصفوف التي حفظتها إصدارات سابقة أو كُتبت مباشرة باستخدام `save_pending_feedback` تُستأنف بدونه: تعمل مستمعات الدالة المراجَعة ومستمعات النتيجة، لكن الخطوات المقطوعة لا تُنفَّذ، وعمليات الدمج وشروط `or_` التي تعتمد على خطوات اكتملت قبل الإيقاف لا تتحقق. يحتوي السجل على أسماء الخطوات المكتملة والمنتظرة وموضع توقف التشغيل، وعلى القيم التي تمررها تلك الخطوات: مخرجات كل خطوة في الطريق إلى الدالة المراجَعة، ونتيجة مراجعة سابقة في ذلك الطريق، بصيغة JSON؛ ويعود القاموس (dict) الذي مفاتيحه أرقام أو قيم منطقية أو `None` أو صفوف (tuple) منها بالمفاتيح نفسها، وتُحفظ القيمة التي لا صيغة JSON لها، مثل قاموس بأي مفتاح آخر أو قيمة تحتوي على نفسها أو قيمة متداخلة بعمق يتجاوز حد التكرار في Python، بصيغتها النصية، وإذا تعذّر الحصول على صيغتها النصية أيضًا تُحفظ باسم نوعها بين قوسين زاويين، مثل `<list>`؛ وتعود نتيجة المراجعة بوصفها `HumanFeedbackResult` تُحفظ مخرجاتها بالطريقة نفسها؛ وعندما يتوقف تشغيل مُستأنَف مرة أخرى وتستأنفه على النسخة نفسها دون `from_pending`، تُمرَّر هذه القيم ومخرجات كل مراجعة في قائمة الانتظار كما هي دون تغيير؛ وعندما تنتظر مراجعات أخرى خلف المراجعة المعلّقة، يحتوي السجل أيضًا على سياق كل منها مع مخرجاتها و`callback_info` الخاص بها، ويُكتب `callback_info` هذا في وسيلة الحفظ المُهيّأة للتدفق، لذا لا تضع فيه بيانات اعتماد. تكتمل الدوال التي تعمل بالتوازي مع الدالة المراجَعة قبل حفظ الإيقاف، فتنتقل نتائجها وعمليات الدمج التي تغذيها إلى الاستئناف؛ ويعمل الدمج بينها وبين دالة مراجَعة عند الاستئناف بنتيجة المراجعة التي أُجيب عنها أخيرًا، بينما يتلقى في التشغيل الذي يُجاب فيه فورًا قيمة الخطوة التي تنتهي أخيرًا أيًّا كانت. إذا طلبت إحدى هذه الدوال مراجعتها الخاصة، يتوقف التدفق لها بعد ذلك: يُعيد استئناف المراجعة الأولى نتيجة معلّقة جديدة للثانية. يُستدعى مزوّد كل مراجعة عند طلبها، لذا أجب عن المراجعات بالترتيب مع التحقق من `context.method_name` في النتيجة المعلّقة. وإذا أطلقت إحداها خطأً، ينتهي التشغيل بذلك الخطأ بدلًا من الإيقاف.
